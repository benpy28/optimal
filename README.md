# Optimal

A desktop OS built on its own from-scratch kernel, written in Rust. The aim is the fastest, leanest and safest OS there is, while running existing Linux programs unchanged.

- Plan: [ROADMAP.md](ROADMAP.md)
- Kernel source: [`kernel/`](kernel/)
- Every push is built and boot-tested in QEMU by GitHub Actions. The bootable ISO is attached to each run under Artifacts.
