Browser engine: CSS parser for css-syntax-3 section 5 as of the 2026 text, with nested rules, nested declarations and speculative declaration parsing, plus every entry point the spec defines (stylesheet, rule list, declaration list, one rule, one declaration, component values, comma-separated component values).
