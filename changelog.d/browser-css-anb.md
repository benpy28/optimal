Browser engine: the CSS An+B microsyntax (css-syntax-3 section 6) in `optimal-css`: recognizes `<an+b>` in component values, whole or as the longest prefix (for `:nth-child(An+B of S)`), serializes it, and tests an index against it. A and B are clamped to `i32`. Passes all 128 An+B cases of SimonSapin/css-parsing-tests and all 87 WPT anb-parsing and anb-serialization cases, and matches a literal model of the grammar on random token streams.
