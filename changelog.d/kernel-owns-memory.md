- The kernel now owns memory. It copies what it needs from the bootloader first, plans physical memory zones (a new zone after any hole over 1 GiB, metadata carved from the zone itself), and runs one buddy allocator per zone.
- It builds and switches to its own page tables: code read+execute, read-only data and RELRO read-only, data no-execute, all RAM (and never MMIO holes) in a direct map at a random 1 GiB-aligned address with 1 GiB or 2 MiB pages, a write-combining framebuffer, and a boot stack with an unmapped guard page at a random address. CPUs without NX or 1 GiB pages are handled. Bootloader memory is reclaimed afterwards.
- A kernel heap (`Box`, `Vec`): checked slabs for up to 2 KiB, with a secret header magic and an allocation bitmap, so freed memory is never written to and double or bad frees stop the kernel with a clear report. Bigger blocks come from the buddy allocator.
- New tests: 16 kernel tests (every free frame handed out once, page permissions per section, direct map coverage, guard page, heap classes, fault injection making allocations and page-table updates fail cleanly), 8 new crash tests (stack overflow, writes to RELRO and code, executing the direct map and the heap, heap double free, bad and wild frees), and a KASLR check that addresses move between boots.
