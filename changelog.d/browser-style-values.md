Browser engine: value grammars in `optimal-style` (css-values-4 at csswg-drafts 7027ab6). Each declaration's value is checked against its property's grammar, read from the value definition syntax and matched over sets of states so every way of matching is followed; math functions are type-checked with the css-typed-om type algebra, with percentage contexts from the grammar. Every grammar is checked against its spec's text. Passes 3,120 of 3,334 WPT value parsing cases; the 214 others are listed with reasons (later spec levels, and 18 errata where a test disagrees with the spec text). The matcher agrees with a literal sentence-by-sentence reading of the spec on random grammars, and runs in linear time on hostile values.
