- Bootloader: Secure Boot and tamper CI for Optimal Boot (OVMF Secure Boot build with fresh test keys): the signed loader boots and its PCR 8 and 9 match a replay computed on the host; the firmware refuses an unsigned, wrongly signed, tampered or dbx-listed loader; the loader refuses a tampered kernel, module or config, a config signed by an untrusted key, and a missing signature. `bootloader/DESIGN.md` describes the loader's internals and how each planned boot-chain mechanism (image root hash, SVN and anti-rollback, A/B slots, PIN entry, microcode, release keys, Secure Boot paths, parser fuzzing) will be built and tested.
