- HPET timer events now reach the CPU by FSB delivery or legacy replacement as well as an I/O APIC input (Phase 1c, step 1c3d2). The comparator and route are chosen in this order: FSB on the highest-numbered comparator that has it (Tn_FSB_INT_DEL_CAP; an MSI straight to the boot CPU's local APIC on vector 0xED, so no I/O APIC input is held), then an edge on a free I/O APIC input as before, then legacy replacement (comparator 0 on ISA IRQ 0, comparator 1 held quiet beside it). QEMU's pc machine, whose comparators reach only GSI 2, now gets HPET events by legacy replacement instead of PIT events with a warning, and by FSB with `-global hpet.msi=on`.
- Legacy replacement is kept, as the last HPET route (decided 28 Nov 2026, written down in kernel/src/timer/hpet.rs): it takes ISA IRQ 0 from the PIT and IRQ 8 from the RTC, so it is used only while the PIT is not giving events and nothing uses the RTC's interrupt. The PIT and legacy replacement each refuse an ISA IRQ 0 vector that already has a handler (`irq::try_set_handler`). Rejected: dropping it (those machines stay on PIT events, 54.9 ms per arming and three port writes) and using it ahead of the I/O APIC route.
- Every route is proved before it is trusted: the comparator is armed 100 us ahead and its interrupt must arrive within 10 ms of its match, in one of three armings (about one in a million to miss three under multi-threaded TCG; a route that does not deliver misses every time), else the route is given back and the next one tried. A route or FSB capability that firmware gets wrong then costs 30 ms at boot instead of events that never come.
- The `timer:` line names the route: `hpet comparator 2 by FSB to APIC 0`, `on GSI 16`, or `by legacy replacement on ISA IRQ 0 (GSI 2)`. `notimer=` gains `hpet-fsb`, `hpet-ioapic` and `hpet-legacy` to rule out one route, and a refusal names each route's reason.
- The HPET's main counter is read whole (two reads with the same high half) everywhere it is a clock or a reference, not only in the timer: on QEMU, which splits a 64-bit read low half first, a carry between the halves read 2^32 ticks (43 s at 100 MHz) high.
- `optimal-apic` gains `msi` (fixed, edge, physical MSI address and data; refuses APIC IDs over 255, which need interrupt remapping, and vectors under 0x20). `optimal-time` gains the FSB route register, FSB and legacy one-shot configurations and `hpet::pick` over all three routes. Hand-worked cases from the specifications and QEMU's registers, property tests against a brute-force search, and mutation testing.
- Kernel tests force the HPET by each route the machine has in turn (FSB, I/O APIC input, legacy replacement) as well as every other source, check each route's registers, and require no route fails its probe. Tough conditions add FSB events (q35 BIOS and UEFI, TCG with 4 CPUs, pc), the I/O APIC route with FSB offered but ruled out, legacy replacement on pc (BIOS, UEFI, TCG) and on q35 with the other two ruled out, and the PIT on pc with legacy replacement ruled out.
