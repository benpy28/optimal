- Optimal Boot: seeded structured fuzzing of the signature, ACPI, TCG event log and device-path parsers (10^5 cases per parser on every PR, 10^8 nightly, with overflow checks on). Fixes found by it: ACPI ranges that wrap the 64-bit address space are refused instead of wrapping, a FACS needs its signature, and the TCG log header is checked against the PC Client firmware profile and the algorithm registry. Device-path walking moved into the tested core; the quirk injector now uses only the first instance of a multi-instance path.
- Optimal Boot: fixed "out of memory for the handoff" on small machines. The page-table reservation was about 38 MiB in one block below 4 GiB on a 160 MiB machine, which KASLR placement could leave no room for; it is now a per-level bound proven against the real mapper by a seeded test (about 6.4 MiB, from up to 64 separate blocks). New conformance case `tiny` (128 MiB) fails on the old loader every time and passes now under ours and Limine (Limine 11.4.1 itself panics at 96 MiB, so 128 MiB keeps the case differential). The handoff's three out-of-memory messages now say which allocation failed. New `ob-boot-volume` check: the boot volume reported to the kernel must be the test disk's GPT partition.
