Browser engine: new `optimal-css` crate with the CSS Syntax Level 3 tokenizer (css-syntax-3 section 4, input preprocessing applied while reading so offsets point into the original text, unicode-range tokens behind the spec's flag, numbers correctly rounded with type flag and sign kept). A stream tokenizer gives the same tokens, errors and offsets for any split of the input, and retries a token only once the unscanned text has doubled, so a long token arriving in small chunks stays linear. Passes all 287 romainmenke/css-tokenizer-tests tests (2 with spec-derived errata), matches a literal model of the spec on random inputs, and has a hostile-input linear-time test.
