Browser engine: defaulting in `optimal-style` (css-cascade-5 sections 3 and 7). A property table of 154 longhands, 29 shorthands and 2 legacy name aliases, each entry checked against the property definition table of the spec it cites. Declarations with unknown properties or misused CSS-wide keywords are dropped by the parser, so runs of declarations split where css-syntax-3 says. Shorthands and `all` cascade as their longhands. Each element gets every property's specified value: inherited or initial when nothing cascades, and `initial`, `inherit`, `unset`, `revert`, `revert-layer` and `revert-rule` resolved by rolling back through the sorted declarations; custom properties are inherited and start out guaranteed-invalid. Checked against a literal model on random sheets and trees, hand-worked cases, 27 web-platform-tests asserts and 20 reftest pages. Not yet: value grammars and computed values, `var()` substitution, logical properties.
