Browser engine: the DOM's "would this insert make a node its own ancestor" check (host-including, as the standard defines it) now uses a link-cut tree and takes O(log n) amortised time at any depth, instead of a walk to the root. Repeated adoption agency runs that move nodes deep in the tree were quadratic because of that walk (`<b><div>x</b>` repeated 20,000 times took 3.3 s, now 51 ms). Two such inputs are added to the hostile-input scaling test.
