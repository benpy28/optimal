- The kernel now runs its own interrupt controllers (Phase 1c part 4). The boot CPU's local APIC goes to x2APIC whenever the CPU has it (unless the DMAR table opts out, or stays in x2APIC if firmware already chose it), with every LVT masked except the error interrupt and the LINT pins the MADT marks NMI, a spurious vector of 0xFF, and anything firmware left in service retired. The legacy 8259s are remapped onto 0x20 to 0x2F and masked. Every I/O APIC pin is programmed from a routing plan: ISA IRQs on their Interrupt Source Overrides (IRQ 0 on GSI 2 on QEMU and most PCs), with the override's polarity and trigger, NMI sources live, everything else masked. Interrupts are then on, with dispatch that counts every vector, retires only what is really in service, and never treats a stray or spurious interrupt as fatal.
- New host-tested crate `optimal-apic`: IA32_APIC_BASE mode changes checked against the SDM's legal transitions, local APIC, x2APIC MSR and I/O APIC register encodings, the 8259 remap sequence run through a model 8259, and the routing plan checked on random MADTs against its rules. Every mutant is caught except equivalent ones (OR of disjoint bit fields), which are listed with the reason. `optimal-acpi` reads the DMAR header flags.
- Fixed before it shipped: firmware that globally disables the local APIC also clears the APIC bit in CPUID, which made the kernel think the CPU had none and run without interrupts. The kernel now reads IA32_APIC_BASE and switches the APIC back on, and reports it.
- Tough conditions: interrupt controllers left dirty (8259s unmasked on the BIOS vectors, every I/O APIC pin live, local APIC LVTs live with a raised TPR) by a test-only kernel option, because Limine tidies the 8259s and I/O APIC before the kernel starts; local APIC states from the firmware-quirk injector (raised TPR and live LVTs, x2APIC already on, globally disabled); DMAR x2APIC opt-out; a CPU without a local APIC. Every tough-conditions run now also checks the `interrupts:` line. 14 new kernel tests, including the PIT's interrupt arriving exactly once through its I/O APIC route only while unmasked, priority order and TPR blocking, and the spurious and stray paths never retiring another interrupt.
