- The kernel is now a static position-independent executable, so Limine loads it at a random address (KASLR). Relocated data lives in a page-aligned RELRO region that the kernel's own page tables will map read-only.
- New `optimal-mm` crate (no_std, no unsafe): a buddy physical frame allocator with metadata kept outside free memory and every free checked, and 4-level x86_64 page-table editing that enforces W^X, canonical addresses, alignment, no silent overwrite, and no change on failure.
- Tested with hand-worked cases (exact page-table entry bits, allocator layouts, every kind of metadata corruption `check()` must catch), seeded property tests against exact reference models (50,000 cases in CI), Kani proofs, and a CI mutation-testing job in which no mutant may survive.
