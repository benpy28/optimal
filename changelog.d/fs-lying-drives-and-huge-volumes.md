- OptimalFS: volumes up to 128 PiB (the space map's depth now scales with the device, and format writes only a few blocks however big the disk is). It survives drives that lie about flushing: freed space is held for 8 commits, every superblock keeps the last 8 commits' roots, and after an unclean shutdown mount checks recent blocks and falls back to the last commit that fully landed. Also new: a clean-unmount flag, a replay counter ready for TPM binding, feature bits, header bytes that never change between commits, and passphrase key derivation sized to the machine's RAM (1 GiB and 4 passes by default, refusing anything below 64 MiB and 4 passes).
