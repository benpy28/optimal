Browser engine: parse trees for property values in `optimal-style`. A valid value now also says how it matched its grammar (which alternative, which `||` child took which component values, how many repetitions), choosing among several ways by fixed rules: greedy left to right (css-values-4 on `<position>`), keywords before `<custom-ident>` (css-values-4 4.2), then grammar order. Checked against a reference that writes out every derivation on random grammars, on every WPT-valid value, and for linear time on hostile values.
